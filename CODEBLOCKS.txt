HOW TO OPEN IN CODE::BLOCKS
===========================

1. Install Code::Blocks with MinGW (or MinGW-w64 separately).

2. Put raylib WIN64 under the project:
     GAMEHUB-final\include\raylib-6.0_win64_mingw-w64\include\raylib.h
     GAMEHUB-final\include\raylib-6.0_win64_mingw-w64\lib\libraylib.a

3. Open:  File → Open → GAMEHUB.cbp

4. Build → Build (or F9)
   Run   → Run (or Ctrl+F10)

If raylib is not found:
  Project → Build options → Search directories
    Compiler: include
              include/raylib-6.0_win64_mingw-w64/include
    Linker:   include/raylib-6.0_win64_mingw-w64/lib
  Linker settings → Link libraries: raylib, opengl32, gdi32, winmm

Working directory for Run should be the project root (so data/ is found).
  Project → Properties → Build targets → Execution working dir: .
