# GAME HUB (Progress Build)

C99 terminal shell with raylib mini-games and persistent session profiles.

## Run

- **Windows:** `run` (or `build.bat` / `make run`)
- **macOS / Linux:** `./run` (or `make run`)

## Commands

- `candy` — Launch Match-3 game
- `status` — View player profile and ratings
- `settings` — System preferences stub
- `help` / `ls` / `exit` — Navigation and session control
